# Payment marks

Original brand artwork, downloaded 2026-10-31 for the clearly labelled demo checkout. These marks do not indicate an active payment integration. Artwork is not recolored, redrawn, cropped, or stretched; CSS uses `object-fit: contain`. Trademarks remain the property of their respective owners.

- Apple Pay: [official marketing resources](https://developer.apple.com/apple-pay/marketing/), [original archive](https://developer.apple.com/apple-pay/marketing/Apple-Pay-Mark.zip), `Apple Pay Mark/SVG/Apple_Pay_Mark_RGB_041619.svg`.
- Google Pay: [official brand guidelines](https://developers.google.com/pay/api/web/guides/brand-guidelines), [original archive](https://developers.google.com/static/pay/api/download-assets/Google-Pay-Acceptance.zip), `Google Pay Mark/google-pay-mark_800.svg`.
- Visa: [Visa merchant brand guidelines](https://visapos.sppone.corpmerchandise.com/brandguidelines), [original archive](https://spponeimages.azureedge.net/prod/ab696eb4-ddcf-48ff-8176-da6fa22ae00eVisa_Brandmark_RGB_2021_SVG.zip?v=0), `Visa_Brandmark_Blue_RGB_2021.svgz`. Only gzip decompression was applied.
- Swish: [official marketing toolbox](https://www.swish.nu/marketing-toolbox/general-guidelines?lang=en), [original site SVG](https://www.swish.nu/assets/swish-logotype-C2_aqj3N.svg).
- Mastercard: original 444 x 278 PNG displayed as "Mastercard Logo" by the [official developer site](https://developer.mastercard.com/), served by its [configured consent-provider CDN](https://cdn.cookielaw.org/logos/1df3f1e6-52a6-46c4-b5a1-0e035b09a859/c8f0ae6e-550f-49f2-bf8d-e209a37a96a7/2dc2e77e-31c9-4bf6-b310-d14722cbe9b4/MicrosoftTeams-image.png). The [Brand Center SVG archive](https://www.mastercard.com/brandcenter/us/en/download-artwork.html) returned HTTP 403, so the unchanged original PNG is used instead of recreated vector artwork.

Review brand usage requirements and merchant eligibility before enabling real payments. No credentials, payment SDKs, external logo requests, or provider connections are introduced by these assets.
